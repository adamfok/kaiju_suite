# Changelog

## Unreleased
- Scripter: new **Selection** item (right-click **New ▸ Selection**, after Export File) that selects objects when the run reaches it, so a following Export File or script works on them. It holds a list of entries: **Selected** objects (or components, one entry per Add Selected), **name patterns** such as `*_geo` (Maya wildcards; several separated by spaces), with a **Type** to find: * (any), Transform, Joint, Geo, Nurbs Curve, Nurbs Surface, Locator or Constraint, where Geo, Nurbs Curve, Nurbs Surface and Locator find the transforms with that shape and **selection sets** (nested sets included). Patterns and sets are looked up again on every run, so they find objects made by earlier steps. Running it replaces the selection with everything the entries find, in entry order, each object once; if an object, pattern or set is missing, the run stops there and names it. Intermediate objects (e.g. `...ShapeOrig`) are never included. **New** starts with the current selection and opens the editor. Double-click one to edit it; the editor doesn't block Maya, so you can select objects while it's open. Each entry shows how many objects it finds (red when something is missing). The icon buttons above the list (or right-click empty space in it) **Add Selected**, **Add Pattern** or **Add Selection Set**; and an entry to **Remove** it. Double-click an entry to change it: a pattern or set asks for its new value; a Selected entry opens a window of its objects (missing ones in red) where picking objects selects them in the scene, and icon buttons at the top **Add Selected**, **Replace with Selected** or **Remove** the picked objects; nothing changes until its **OK**. Below, the **Preview** lists what the clicked entries find (click empty space to see all of them), with its object count; clicking an entry looks it up in the scene again. Pick objects in the preview to select them in the scene, or right-click it ▸ **Select All**. Hover the item's name to see its entries. Not versioned

- Assembler: new **Leg Guide** guide module (right-click **New ▸ Leg Guide**), a biped leg with its foot. The ankle guide is shared: there's one ankle joint, and the ball and toe joints hang under it. Three red move-only locators, `<name>_heel_pivot`, `<name>_inner_pivot` and `<name>_outer_pivot`, mark the reverse foot's pivots (they aren't joints). In the Guide Module Editor a Leg Guide has **Leg Aim**, **Leg Up**, **Foot Aim** and **Foot Up** (no # Mid): the foot's joints turn on their own axes, independently of the leg's, and both are saved in the file and reversed by Mirror (a new item starts with the foot on the leg's axes). Building a Leg Guide again on the joints Delete left isn't supported yet: delete those joints first
