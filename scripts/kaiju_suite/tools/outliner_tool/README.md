# Outliner Tool

The Outliner Tool provides various utilities for working with nodes in the Maya outliner.

## Features

### Main Functionality
- Rename nodes using pattern-based replacements
- Preview rename operations
- Group, chain and offset operations (buttons below input field)
- Lock/Unlock buttons for channel box attributes

### Lock/Unlock Buttons
- **Lock Button**: Locks translate, rotate, scale, and visibility attributes for selected joints.
- **Unlock Button**: Unlocks translate, rotate, scale, and visibility attributes for selected joints.

## Usage

1. Select one or more nodes in Maya.
2. Open the Outliner Tool from the Kaiju menu.
3. Use the Lock/Unlock buttons to control channel box attributes.

## Notes

The Lock/Unlock functionality properly manages channel box attribute locks, and the buttons are positioned at the bottom of the tool window for easy access.
